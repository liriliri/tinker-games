# Tinker Chess

A browser-ready international chess plugin for Tinker. Play locally with two
people or challenge the built-in Dreamer-inspired computer opponent.

## Rules

- Standard 8 × 8 chess with legal move validation
- Castling, en passant, promotion, check, checkmate and stalemate
- Threefold repetition, the fifty-move rule and insufficient-material draws
- Keyboard controls: arrow keys or WASD to move, Enter/Space to select, `U`
  to undo, `R` to restart and Escape to open the menu

## Development

```bash
npm run dev
npm run build
```
